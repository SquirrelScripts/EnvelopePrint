Printing tips

  • In the print dialog, set Margins to None and Scale to Default / 100%, and turn off Headers and footers.
  • Test on plain paper prints the outline on a regular sheet. Hold an envelope (or a label sheet, up to the light) against it to check the layout.
  • Then print one real envelope or sheet. If it lands off, fix it under Printer adjustments. Those settings are saved.

How to print addresses on envelopes

  1. Add your addresses. Type or paste them with a blank line between each one, paste cells from a spreadsheet, or import a CSV file.
  2. Pick what you're printing on. Envelopes, postcards or an Avery-style label sheet. #10 is the standard business envelope; cards usually use A2, A7 or C6.
  3. Place things. Drag the address, return address, logo and decoration where you want them. The standard layout is already set up.
  4. Check it on plain paper. Test on plain paper prints an outline you can hold an envelope or label sheet against.
  5. Print one real envelope, then the batch. If it lands a little off, fix it once under Printer adjustments and it's remembered. Or Save PDF to print later.

Questions

How do I print envelopes from an Excel or Google Sheets list?

Select the cells (including the header row) and paste them into the recipients box, or save the sheet as CSV and use the import button (the up-arrow under the address box). Starting from nothing? The template button next to it gives you a spreadsheet with the columns already named: fill in one address per row, save it as CSV, and import it. Its two example rows are skipped automatically. Columns like First Name, Last Name, Company, Address, Address 2, City, State, ZIP and Country are recognized and assembled into a proper mailing address. ZIP codes that lost their leading zero (2134 instead of 02134) are fixed automatically.

Can I print address labels instead?

Yes. Choose Labels under Print on, then your sheet: Avery 5160 / 8160 (30 per sheet) is the usual address label, and 5167 is the small return-address label. A4 sheets L7160 and L7163 are there too. Long addresses shrink to fit their label, and you can start part-way down a half-used sheet. Pick My return address to fill a whole sheet with return labels, with your logo beside the text if you've added one.

How do I print the return address on the back flap?

Under Return address, set Where to Back flap. Use Front / Back above the preview to place it (it's centred by default). Print the fronts, flip the stack over, and press Print back flaps. If the backs come out upside down, tick Turn back flaps upside down under Printer adjustments.

Can I keep my Christmas card list for next year?

Yes. Keep as many named lists as you like with the menu above the address box. The Card tracker lets you tick who you sent a card to and who sent you one. Next year, choose New list from this one and keep only the people who sent you a card. Use Back up everything now and then; the lists only live in this browser.

Why is the address printing in the wrong spot?

Every printer feeds envelopes a little differently. Print one envelope, measure how far off it is, and enter that under Printer adjustments (a negative number moves left or up). If it comes out sideways or upside down, change Rotate envelopes for printer. In the print dialog, set Margins to None and Scale to 100%.

Can I address wedding invitations or holiday cards?

Yes. Pick a script font under Text (Great Vibes, Pinyon Script, Parisienne and others) at 16–20pt, set Alignment to Centred, and choose an ink colour. The merge button next to the address box turns guests who share an address into one envelope ("John and Ann Smith" or "The Smith Family"). Put the return address on the back flap, and add a flourish under Decoration: there are faith symbols (cross, dove, chalice and host, Sacred Heart, rosary, Marian M, lilies and more) alongside holiday and celebration ones, in full colour or matched to your ink. Envelope colour previews kraft, blush or navy stock.

My list is messy. Can it clean it up?

The ✨ Tidy up button fixes spacing and all-lowercase names, turns "Street" into "St", "Apartment" into "Apt" and full state names into their two-letter codes, puts the comma in "City, ST ZIP", and removes exact duplicates. It keeps ALL-CAPS lines as they are, and there's an Undo. Addresses that look wrong (a missing ZIP, an unknown state, both a PO Box and a street) are flagged in amber under the preview.

Can I use it offline, like a normal app?

Yes. In Chrome or Edge, press Install app at the top (or use the install icon in the address bar). It opens in its own window and keeps working without internet, fonts included, once they've loaded once.

Are my addresses uploaded anywhere?

No. This is a single web page that runs entirely in your browser. Your lists, return address and logo are only saved in your own browser so they're there next time, and none of it is ever sent anywhere. The page itself loads its fonts from Google Fonts and counts anonymous visits (GoatCounter, no cookies) so we know whether people use it; neither ever sees your addresses.

Which browser should I use?

Chrome or Edge give the most reliable envelope sizing when printing. It works on Windows and Mac. If a browser won't size the page right, use Save PDF and print the PDF.
