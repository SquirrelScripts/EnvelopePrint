Printing tips

  • In the print dialog, set Margins to None and Scale to Default / 100%, and turn off Headers and footers.
  • Test on plain paper prints the envelope outline on a regular sheet. Hold an envelope over it to check the layout.
  • Then feed one real envelope with Print this one. If the text lands off, fix it under Printer adjustments. Those settings are saved.

How to print addresses on envelopes

  1. Add your addresses. Type or paste them with a blank line between each one, paste cells from a spreadsheet, or import a CSV file.
  2. Pick the envelope size. #10 is the standard business envelope. Greeting cards usually use A2, A7 or C6.
  3. Place things. Drag the address, return address and logo where you want them. The standard layout is already set up.
  4. Check it on plain paper. Test on plain paper prints an outline you can hold an envelope against.
  5. Print one real envelope, then the batch. If it lands a little off, fix it once under Printer adjustments and it's remembered.

Questions

How do I print envelopes from an Excel or Google Sheets list?

Select the cells (including the header row) and paste them into the recipients box, or save the sheet as CSV and use Import spreadsheet. Columns like First Name, Last Name, Company, Address, Address 2, City, State, ZIP and Country are recognized and assembled into a proper mailing address. ZIP codes that lost their leading zero in the spreadsheet (2134 instead of 02134) are fixed automatically.

Why is the address printing in the wrong spot?

Every printer feeds envelopes a little differently. Print one envelope, measure how far off it is, and enter that under Printer adjustments (a negative number moves left or up). If it comes out sideways or upside down, change Rotate for printer. In the print dialog, set Margins to None and Scale to 100%.

Are my addresses uploaded anywhere?

No. This is a single web page that runs entirely in your browser. Your list, return address and logo are only saved in your own browser so they're there next time, and none of it is ever sent anywhere. The page does count anonymous visits (GoatCounter, no cookies) so we know whether people use it.

Which browser should I use?

Chrome or Edge give the most reliable envelope sizing when printing. It works on Windows and Mac.

Can I add a logo?

Yes. Choose an image in the Logo panel or drop one onto the envelope preview, then drag it into place and pull its corner to resize. Tick Print in black & white for a mono printer.
